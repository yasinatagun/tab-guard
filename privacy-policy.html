# Privacy Policy for TabGuard **Last updated: November 9, 2026** TabGuard is a Chrome browser extension designed to automatically close tabs that match website rules configured by the user. ## 1. Information We Collect TabGuard does not collect personal information, browsing history, or usage analytics. The extension does not require user registration or an account. ## 2. How TabGuard Works TabGuard accesses browser tab URLs to determine whether they match user-defined rules. All URL matching and tab-closing operations are performed locally within the user's browser. TabGuard does not transmit browsing URLs to external servers. ## 3. Local Data Storage TabGuard stores user-created website rules, schedules, and extension preferences locally using Chrome's extension storage. This information is used exclusively to provide the extension's functionality. ## 4. Data Sharing TabGuard does not sell, share, or transmit user data to third parties. ## 5. Data Security TabGuard does not operate a remote server for collecting or processing browsing activity. User configurations remain within the browser's local storage. ## 6. Children's Privacy TabGuard does not knowingly collect personal information from children or other users. ## 7. Changes to This Policy This privacy policy may be updated if TabGuard's functionality or data practices change. Updates will be published on this page. ## 8. Contact For questions about this privacy policy, please contact the developer using the contact email listed on the TabGuard Chrome Web Store page.
